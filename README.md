# encendidos-legal

Páginas públicas de **Encendidos by GEENERA** (política de privacidad y soporte), publicadas con GitHub Pages:

- https://geenera-sas.github.io/encendidos-legal/
- https://geenera-sas.github.io/encendidos-legal/privacidad.html
- https://geenera-sas.github.io/encendidos-legal/soporte.html

**Fuente de verdad:** `docs/privacidad.md` en el repositorio privado `GEENERA-sas/encendidos`. Este sitio es una copia pública generada a partir de ese archivo: cualquier cambio a la política se hace primero allá, con revisión del Área Jurídica de GEENERA, y luego se vuelve a publicar aquí.

El sitio es HTML estático: sin cookies, sin analítica, sin rastreadores y sin scripts externos (solo la tipografía Titillium Web desde Google Fonts).
